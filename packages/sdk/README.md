# Общий код окон Extract Moon

Плеер, проводник запусков и справочник архитектур берут общие части отсюда. Если что-то нужно двум окнам, оно живёт здесь, а не копируется.

| Подключение | Что даёт |
|---|---|
| `@extract-moon/sdk/backend` | связь окна с сервисом на Python: адрес, токен, запросы |
| `@extract-moon/sdk/fonts` | шрифты IBM Plex |
| `@extract-moon/sdk/gizmo` | гизмо осей: щелчок задаёт вид, перетаскивание вращает камеру |
| `@extract-moon/sdk/video` | покадровый рендер в MP4, подпись в углу кадра |
| `@extract-moon/sdk/video-size` | список размеров видео и рамка кадра на сцене |
| `@extract-moon/sdk/style.css` | стили гизмо и размера видео, цвета задаются переменными `--gizmo-*` |

Общая часть на Rust лежит в `packages/shell`: состояние `Backend`, запись файлов, открытие папки и пакетное задание.

Пакеты подключены через npm workspaces, поэтому `npm install` выполняется один раз из корня проекта.
