# Справочник архитектур на Tauri

3D-справочник моделей на three.js в отдельном окне. Слева архитектуры и запуски, в центре модель, справа карточка выбранного блока.

Окно ничего не считает. Каталог схем и память слоёв по чекпойнтам даёт сервис `python/src/extract_moon/model_viewer/`: он слушает 127.0.0.1 на свободном порту и передаёт окну адрес и токен через переменные окружения.

## Сборка

Нужны Node.js, Rust и MSVC. Зависимости ставятся один раз из корня проекта, общий код лежит в `packages/`:

```bash
npm install
```

Сборка выполняется из папки `models_app/`:

```bash
npm run tauri -- build --no-bundle
```

Готовый файл: `src-tauri/target/release/extract-moon-models.exe`. Сам по себе он не работает, запускать его нужно через Python.

## Запуск

Кнопкой «Визуализатор» в проводнике запусков или из папки `python/`:

```bash
uv run extract-moon models
```

Сервис живёт, пока открыто окно. Повторный запуск выводит открытое окно на передний план и завершается.

Без окна, для проверки в браузере:

```bash
uv run extract-moon models --serve --port 8792
```

Команда печатает адрес с токеном. Сервис отдаёт собранный интерфейс из `dist/`, поэтому нужен `npm run build`.

## Пролёты и запись видео

Кнопка «Пролёт» открывает панель. «Просмотр» показывает маршрут в окне, «Рендерить» снимает ролик покадрово и сохраняет его с файлом параметров в `data/videos`. Маршрут зависит только от времени, поэтому просмотр и ролик совпадают. Рамка на сцене показывает кадр видео, если он уже окна.

| Маршрут | Что делает камера |
|---|---|
| Сверху, от начала до конца | идёт над моделью вдоль потока данных |
| Изометрия, от начала до конца | тот же проход под изометрическим углом |
| По группам | переходит между выбранными группами и задерживается на каждой, в любую сторону |
| Облёт вокруг модели | делает оборот вокруг центра |
| Текущий вид | стоит на месте, потоки данных движутся |

Проекция, скорость и размер кадра задаются для любого маршрута, по умолчанию 1920 × 1080. На задержке пролёта по группам группа подсвечена, а в кадре стоят её название и назначение. Потоки данных идут весь ролик. Подписи блоков и групп попадают в кадр, если включена кнопка «Подписи». Флажок «Легенда» добавляет в угол архитектуру, число весов, модель и цвета групп.

## Пакетный рендер

Переменная `EXTRACT_MOON_JOB` с путём к JSON снимает один ролик без диалогов и закрывает окно. Окно справочника при этом должно быть закрыто. При ошибке рядом с роликами появляется `<stem>.error.txt`.

```json
{ "kind": "groups", "speed": 1.5, "pause": 2, "from": "encoder", "to": "heads", "ortho": true, "stem": "tour" }
```

Необязательные поля: `arch`, `run`, `seconds`, `width`, `height`, `legend`.
