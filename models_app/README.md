# Справочник архитектур на Tauri

3D-справочник моделей на three.js в отдельном окне. Слева архитектуры и запуски, в центре модель, справа карточка выбранного блока.

Окно ничего не считает. Каталог схем и память слоёв по чекпойнтам даёт сервис `python/src/extract_moon/model_viewer/`: он слушает 127.0.0.1 на свободном порту и передаёт окну адрес и токен через переменные окружения.

## Сборка

Нужны Node.js, Rust и MSVC. Команды выполняются из папки `models_app/`:

```bash
npm install
```

```bash
npm run tauri -- build --no-bundle
```

Готовый файл: `src-tauri/target/release/extract-moon-models.exe`. Сам по себе он не работает, запускать его нужно через Python.

## Запуск

Кнопкой «Визуализатор» в проводнике запусков или из папки `python/`:

```bash
uv run extract-moon models
```

Сервис живёт, пока открыто окно. Повторный запуск выводит открытое окно на передний план и завершается.

Без окна, для проверки в браузере:

```bash
uv run extract-moon models --serve --port 8792
```

Команда печатает адрес с токеном. Сервис отдаёт собранный интерфейс из `dist/`, поэтому нужен `npm run build`.
