# Инструкции для агентов

Проект — песочница обучения с подкреплением: фракции роботов заряжают общий корабль, мест на всех не хватает. Замысел и правила мира — в [README.md](README.md), устройство кода и команды — в [python/README.md](python/README.md).

- Перед любым обучением и при любом изменении симуляции, наград или конфига следуй [EXPERIMENTS.md](EXPERIMENTS.md): коммит перед запуском, версия правил, `LEGACY` для новых параметров, имена запусков, запись в [data/journal.md](data/journal.md).
- Видеокарта GTX 1050 с драйвером 472.12, который нельзя обновлять. Версии библиотек подобраны под CUDA 11.8 (см. python/README.md); не обновляй torch без проверки совместимости.
- Свободной видеопамяти около 1,1 ГБ: два обучения одновременно не помещаются.
- Команды запускаются из папки `python/` через `uv run`.
- Окна на Tauri (`player/`, `explorer_app/`, `models_app/`) используют общий код из `packages/sdk` и `packages/shell`. Что нужно двум окнам, выноси туда, а не копируй.
- Меняешь архитектуру в `model.py` — обнови схему в `python/src/extract_moon/model_viewer/schemas/` (или добавь новую версию) и её `model_commit`; `tests/test_model_schema.py` должен проходить.
