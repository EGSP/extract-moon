# Новый плеер Extract Moon

3D-проигрыватель реплеев на Tauri и three.js с интерфейсом в стиле Carbon. Работает отдельно от плеера на pygame и читает те же файлы `.jsonl.gz`.

## Сборка

Нужны Node.js, Rust и MSVC. Команды выполняются из папки `player/`:

```bash
npm install
```

```bash
npm run tauri -- build --no-bundle
```

Готовый файл: `src-tauri/target/release/extract-moon-player.exe`.

## Запуск

В проводнике запусков выберите запуск и, при желании, модель, затем нажмите «Новый плеер». Для модели без записанного этапа проводник сначала сыграет новый матч на CPU.

Из папки `python/`:

```bash
uv run extract-moon player r3-base
```

Можно передать имя запуска, папку или файл реплея. Этапы того же запуска переключаются кнопками в шапке.

## Управление

| Действие | Мышь или кнопка | Клавиша |
|---|---|---|
| Вращать камеру | левая кнопка | |
| Сдвинуть камеру | правая кнопка | |
| Приблизить | колесо | |
| Вид вдоль оси | щелчок по оси гизмо | 1, 3, 7 |
| Вращать камеру через гизмо | перетаскивание по гизмо | |
| Общий вид | кнопка под гизмо | 0 |
| Ортографическая проекция | кнопка под гизмо | 5 |
| Пуск и пауза | кнопка | пробел |
| Такт назад и вперёд | кнопки | ←, → |
| Скорость | список | ↑, ↓ |
| Значки, обзор, плавность | кнопки | H, V, I |
| Снимок, видео, папка | кнопки | S, M, O |
| Выбрать робота | щелчок | Tab |

Снимок сохраняется в папку `screens` рядом с реплеем, видео сохраняется рядом с реплеем.

Видео рендерится покадрово, поэтому его плавность не зависит от видеокарты. В ролик попадают текущие камера, проекция, скорость, плавность, значки, зоны обзора и выбранный робот. Перед рендером открывается окно с таймлайном матча, включая взлёт корабля. Части команд входят в ролик целиком, а промежутки до них, между ними и после можно вырезать щелчком по таймлайну или флажком. Если команд с длительностью нет, выбирается один диапазон тактов. Выбранные диапазоны записываются в JSON. Размер кадра задаёт список «Размер видео»: варианты «Как окно» берут пропорции окна, остальные от окна не зависят, а «Свой размер» принимает ширину и высоту. Если кадр уже окна, на сцене видна его рамка. Флажок «Легенда» добавляет в левый нижний угол ролика модель, прогон и матч.

Рядом с видео сохраняется файл `<реплей>_3d.json` с параметрами экспорта: разрешение, кодек, скорость, настройки отображения, реплей с моделью и камера (проекция, положение, цель, угол обзора или высота кадра).

## Анимация камеры

Вкладка «Команды» на правой панели запоминает действия для видео.

- «Начать вращение» (R) наводит камеру на центр карты, запускает вращение вокруг него и записывает такт начала и исходный вид. Расстояние и наклон камеры не меняются, а скорость задаётся в градусах за секунду ролика. Повторное нажатие записывает такт конца.
- «Следовать за роботом» (F) ведёт камеру за выбранным роботом и не поворачивает её. «Следовать с поворотом» (G) дополнительно разворачивает камеру в сторону его движения. Если робот не выбран, кнопка ждёт щелчка по нему в сцене. Робот становится точкой, вокруг которой строится кадр, а расстояние и наклон берутся из вида в момент запуска. Повторное нажатие завершает следование. Погибшего или севшего в корабль робота камера оставляет в его последней точке.
- «Запомнить вид» (P) фиксирует текущий вид с этого такта.
- «Кинокамера» (C) снимает матч сама, «Кинокамера на весь матч» сразу ставит клип от начала до конца. Режим задаётся списком рядом с кнопкой.

Действия собраны в таблице: их можно выключить флажком или удалить, а щелчок по строке переходит к такту начала. На каждом такте работает последнее начавшееся включённое действие, до первого действия камера стоит в его исходном виде.

Те же действия показаны клипами над полосой матча. Края клипа растягивают действие, сам клип сдвигает его целиком, щелчок переходит к такту начала. Пересекающиеся действия лежат на разных дорожках. У вида нет длительности: его клип тянется до следующего действия, и двигать можно только начало. У клипа кинокамеры риски отмечают смену планов.

Поворот при следовании считается по смещению робота за несколько тактов, а не по каждому шагу. Поэтому шаги влево-вправо и стоянка камеру не вращают, а ходьба туда-обратно не накапливает обороты.

### Кинокамера

План съёмки строится заранее из реплея, поэтому ролик совпадает с тем, что видно на экране. Точки интереса — события матча с весами: гибель, рождение, посадка, атака, передача энергии, каждая четверть заряда корабля, отсчёт до взлёта, встречи фракций и группы своих. Для каждого плана камера выбирает место с наибольшей взвешенной плотностью событий, а недавно показанные места получают штраф. Если событий нет, в кадр попадает бодрствующий робот. Если корабль улетает, последний план начинается у земли, а с отрывом цель держится точно на корабле: камера сначала отстаёт и смотрит снизу, затем по спирали догоняет его и смотрит сверху на карту. В режиме «Репортаж» облёта нет.

| Режим | План, секунд ролика | Подача |
|---|---|---|
| Наблюдатель | 8–13 | широкие виды, медленный облёт, планы перетекают друг в друга без склеек |
| Репортаж | 2,5–4,5 | камера на каждом плане неподвижна, планы сменяются только резкими склейками |
| Крупный план | 3–5,5 | камера вплотную идёт за участником события, большинство переходов склейками |
| Боевик | 1,6–3,2 | близкие и низкие планы, только склейки перед сильными событиями |

Длительность плана задана в секундах ролика, поэтому при смене скорости план перестраивается.

### Пакетный рендер

Переменная `EXTRACT_MOON_JOB` с путём к JSON запускает плеер без диалогов: он снимает один клип кинокамеры, сохраняет ролик рядом с реплеем и закрывается. При ошибке рядом появляется `<stem>.error.txt`.

```json
{ "mode": "reporter", "speed": 2, "vision": false, "stem": "r3_l2_u300_reporter" }
```

Необязательные поля: `from`, `to`, `width`, `height`, `icons`, `legend`. Скорость берётся из списка плеера.

Пока есть включённые действия, кнопка видео показывает звезду и рендерит ролик с анимацией в файл `<реплей>_3d_anim.mp4`. Сами действия попадают в JSON рядом с роликом. Команды хранятся отдельно для каждого реплея и сохраняются между запусками.

## Модели

Файлы лежат в `public/models/` и собираются скриптом:

```bash
npm run models
```

Их можно заменить своими GLB, если сохранить имена узлов и материал `paint`, который перекрашивается в цвет фракции. Единица длины равна клетке карты. Список узлов приведён в `tools/make_models.mjs`.
