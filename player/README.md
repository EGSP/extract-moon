# Новый плеер Extract Moon

3D-проигрыватель реплеев на Tauri и three.js с интерфейсом в стиле Carbon. Работает отдельно от плеера на pygame и читает те же файлы `.jsonl.gz`.

## Сборка

Нужны Node.js, Rust и MSVC. Команды выполняются из папки `player/`:

```bash
npm install
```

```bash
npm run tauri -- build --no-bundle
```

Готовый файл: `src-tauri/target/release/extract-moon-player.exe`.

## Запуск

В проводнике запусков выберите запуск и, при желании, модель, затем нажмите «Новый плеер». Для модели без записанного этапа проводник сначала сыграет новый матч на CPU.

Из папки `python/`:

```bash
uv run extract-moon player r3-base
```

Можно передать имя запуска, папку или файл реплея. Этапы того же запуска переключаются кнопками в шапке.

## Управление

| Действие | Мышь или кнопка | Клавиша |
|---|---|---|
| Вращать камеру | левая кнопка | |
| Сдвинуть камеру | правая кнопка | |
| Приблизить | колесо | |
| Вид вдоль оси | щелчок по оси гизмо | 1, 3, 7 |
| Вращать камеру через гизмо | перетаскивание по гизмо | |
| Общий вид | кнопка под гизмо | 0 |
| Ортографическая проекция | кнопка под гизмо | 5 |
| Пуск и пауза | кнопка | пробел |
| Такт назад и вперёд | кнопки | ←, → |
| Скорость | список | ↑, ↓ |
| Значки, обзор, плавность | кнопки | H, V, I |
| Снимок, видео, папка | кнопки | S, M, O |
| Выбрать робота | щелчок | Tab |

Снимок сохраняется в папку `screens` рядом с реплеем, видео сохраняется рядом с реплеем.

Видео рендерится покадрово, поэтому его плавность не зависит от видеокарты. В ролик попадают текущие камера, проекция, скорость, плавность, значки, зоны обзора и выбранный робот. Ролик всегда охватывает весь матч, включая взлёт корабля. Размер кадра задаёт список «Качество», а пропорции берутся из окна.

Рядом с видео сохраняется файл `<реплей>_3d.json` с параметрами экспорта: разрешение, кодек, скорость, настройки отображения, реплей с моделью и камера (проекция, положение, цель, угол обзора или высота кадра).

## Анимация камеры

Вкладка «Команды» на правой панели запоминает действия для видео.

- «Начать вращение» (R) запускает вращение вокруг центра карты и записывает такт начала и исходный вид. Расстояние и наклон камеры не меняются, а скорость задаётся в градусах за секунду ролика. Повторное нажатие записывает такт конца.
- «Следовать за роботом» (F) ведёт камеру за выбранным роботом и не поворачивает её. «Следовать с поворотом» (G) дополнительно разворачивает камеру в сторону его движения. Если робот не выбран, кнопка ждёт щелчка по нему в сцене. Робот становится точкой, вокруг которой строится кадр, а расстояние и наклон берутся из вида в момент запуска. Повторное нажатие завершает следование. Погибшего или севшего в корабль робота камера оставляет в его последней точке.
- «Запомнить вид» (P) фиксирует текущий вид с этого такта.

Действия собраны в таблице: их можно выключить флажком или удалить, а щелчок по строке переходит к такту начала. На каждом такте работает последнее начавшееся включённое действие, до первого действия камера стоит в его исходном виде.

Пока есть включённые действия, кнопка видео показывает звезду и рендерит ролик с анимацией в файл `<реплей>_3d_anim.mp4`. Сами действия попадают в JSON рядом с роликом. Команды хранятся отдельно для каждого реплея и сохраняются между запусками.

## Модели

Файлы лежат в `public/models/` и собираются скриптом:

```bash
npm run models
```

Их можно заменить своими GLB, если сохранить имена узлов и материал `paint`, который перекрашивается в цвет фракции. Единица длины равна клетке карты. Список узлов приведён в `tools/make_models.mjs`.
