# Godot-проигрыватель (будущий)

Здесь будет проигрыватель реплеев на Godot. Пока его роль выполняет pygame-проигрыватель
из `python/` (`extract-moon view <реплей>`), а формат реплея уже рассчитан на чтение из Godot.

## Формат реплея

Файл `data/replays/*.jsonl.gz` — gzip, внутри JSON Lines (одна JSON-запись на строку).

**Строка 1 — заголовок:**

| Поле | Содержимое |
|---|---|
| `format`, `version` | `"extract_moon_replay"`, `1` |
| `seed` | seed карты |
| `model` | `checkpoint`, `update`, `steps` — какой версией модели сыгран матч |
| `map` | `size` (сторона карты в клетках), `factions` |
| `config` | полный конфиг мира, наград и модели |
| `names` | подписи: `main` (12 действий), `upgrade` (4), `symbols` (греческие буквы, индекс 0 — молчание) |
| `result` | итог матча: улетел ли корабль, пассажиры по фракциям, убийства и т. п. |

**Остальные строки — кадры, по одному на такт:**

| Поле | Содержимое |
|---|---|
| `t` | номер такта |
| `ship` | `x`, `y`, `charge`, `capacity`, `seats`, `passengers`, `passenger_faction`, `launch_timer` (-1 — ещё не заряжен) |
| `sources` | список `[x, y, запас]` непустых источников энергии |
| `robots` | `id` (уникален за матч), `slot`, `x`, `y`, `faction` (-1 — одиночка), `status` (`awake`/`asleep`/`boarded`), `energy`, `hp`, `upgrades` [ёмкость, броня, добыча] |
| `events` | что произошло на такте, который привёл к этому кадру: `attack`, `give`, `deposit`, `board`, `leave`, `death`, `sleep`, `wake`, `birth`, `upgrade`, `signal` (`sym`, `val`, `x`, `y`), `launch`/`timeout` |
| `decisions` | по `id` бодрствующего робота: вероятности голов `main`, `upgrade`, `symbol`, `value_level`, выбранные действия `chosen` и оценка критика `critic`. Это решения, принятые **в этом кадре** (их последствия — в следующем) |

Координаты — клетки, `x` вправо, `y` вниз. В одной клетке может стоять несколько роботов.
