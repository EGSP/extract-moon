# Проводник запусков на Tauri

Дерево запусков, страница запуска, шкала моделей, графики и их анимация. Зависимости те же, что у плеера в `player/`: светлая тема Carbon, IBM Plex, иконки Carbon, графики на canvas.

Окно ничего не считает. Склейку с предками, сглаживание и экспорт выполняет сервис `python/src/extract_moon/explorer_app.py`: он слушает 127.0.0.1 на свободном порту и передаёт окну адрес и токен через переменные окружения.

## Сборка

Нужны Node.js, Rust и MSVC. Зависимости ставятся один раз из корня проекта, общий код лежит в `packages/`:

```bash
npm install
```

Сборка выполняется из папки `explorer_app/`:

```bash
npm run tauri -- build --no-bundle
```

Готовый файл: `src-tauri/target/release/extract-moon-explorer.exe`. Сам по себе он не работает, запускать его нужно через Python.

## Запуск

Двойным щелчком по `Запуски Tauri.bat` в корне проекта или из папки `python/`:

```bash
uv run extract-moon explorer-app
```

Сервис живёт, пока открыто окно. Кнопка «Визуализатор» открывает отдельное окно справочника из `models_app/`, оно работает независимо от проводника.

Без окна, для проверки в браузере:

```bash
uv run extract-moon explorer-app --serve --port 8791
```

Команда печатает адрес с токеном. Сервис отдаёт собранный интерфейс из `dist/`, поэтому нужен `npm run build`. Кнопка выбора файла в окне экспорта есть только в Tauri, в браузере путь вводится вручную.

## Экран

- Слева дерево запусков. Щелчок выбирает запуск, двойной щелчок открывает матчи, стрелки вверх и вниз ходят по списку.
- Вкладка Обзор: текущие значения, шкала и таблица моделей, паспорт запуска. Щелчок по шкале выбирает ближайшую модель, двойной щелчок по строке таблицы играет новый матч.
- Вкладка Графики: 13 панелей. Вид Вся ветка склеивает запуск с предками, вид Только запуск показывает его один, вид Сравнение кладёт несколько запусков на общие оси. Щелчок по заголовку открывает один график, вернуться можно через список внизу.
- Анимация работает в виде Вся ветка. Пробел запускает и останавливает её, скорость задаётся в обновлениях в секунду.
- Экспорт вызывает `extract-moon plot-video`, поэтому в видео вид графиков matplotlib, а не интерфейса. По умолчанию файл сохраняется в папку запуска.

Значения взлётов усреднены по последним 200 матчам и отстают от модели, об этом напоминают подписи на шкале и на графике.
